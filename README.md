## 📌 Project Overview
This project focuses on analyzing customer churn data to identify the key factors that lead to customer attrition. Customer churn is a major challenge for businesses, and understanding the reasons behind it can help improve customer retention strategies.

In this project, I performed data cleaning, exploratory data analysis (EDA), and visualization to uncover meaningful insights from the dataset.

---

## 🎯 Objectives
- To analyze customer behavior and identify churn patterns  
- To understand which factors influence customer churn  
- To provide insights that can help businesses reduce churn  

---

## 🛠️ Tools & Technologies Used
- Python 🐍  
- Pandas  
- NumPy  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

---

## 📂 Dataset Description
The dataset contains customer-related information such as:
- Gender  
- Senior Citizen status  
- Contract type  
- Monthly charges  
- Total charges  
- Tenure  
- Churn status  

---

## 🔍 Steps Performed
1. Data Cleaning  
   - Handled missing values  
   - Corrected data types  

2. Exploratory Data Analysis (EDA)  
   - Analyzed distribution of variables  
   - Compared churn vs non-churn customers  

3. Data Visualization  
   - Count plots  
   - Bar charts  
   - Relationship analysis  

---

## 📈 Key Insights
- Customers with **month-to-month contracts** have higher churn  
- **Senior citizens** are more likely to churn  
- Higher **monthly charges** lead to increased churn probability  
- Customers with longer tenure are less likely to leave  

---

## 🚀 Conclusion
This analysis helps in understanding customer behavior and provides valuable insights for reducing churn. Businesses can use these insights to improve customer satisfaction and retention strategies.
